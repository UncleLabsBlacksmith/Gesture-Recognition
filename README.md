## 🚀 ติดตั้ง

> ⚠️ รองรับ **Python 3.12 เท่านั้น** (ให้สอดคล้องกับ `mediapipe==0.10.21` และ `opencv-contrib-python==4.11.0.86`)

เปิด **Command Prompt (cmd)** ในโฟลเดอร์โปรเจกต์ แล้วรันตามลำดับ:

```bat
py -3.12 -m venv venv
.\venv\scripts\activate
```

```bat
pip install opencv-contrib-python==4.11.0.86
pip install mediapipe==0.10.21
pip install pyautogui
pip install sounddevice numpy requests edge-tts playsound==1.2.2
```

> ใช้ **cmd** ในการ activate venv (ถ้าใช้ PowerShell คำสั่ง activate จะต่างออกไป)
> `playsound` ไม่ได้ถูกใช้ในเวอร์ชันนี้แล้ว (เล่นเสียงผ่าน Windows MCI) จะไม่ติดตั้งก็ได้

## ▶️ เริ่มใช้งาน

```bat
python tony_stark_interface.py
```

### 🔑 ตั้งค่า API key (OpenRouter)

เปิดโปรแกรมครั้งแรกโดยยังไม่มีคีย์ จะมี **ป๊อปอัปให้วาง API key** (สร้างได้ที่ [openrouter.ai/keys](https://openrouter.ai/keys))

- คีย์ที่บันทึกจะ **เข้ารหัสด้วย Windows DPAPI** เก็บที่ `%APPDATA%\TonyStarkInterface\api_key.bin` — อยู่นอกโฟลเดอร์โปรเจกต์ จึงไม่หลุดขึ้น GitHub และถอดรหัสได้เฉพาะบัญชี Windows ของคุณ
- ครั้งต่อไปใช้อัตโนมัติ ไม่ต้องกรอกอีก
- **ลบ/เปลี่ยนคีย์** ได้ที่ **⚙ ตั้งค่า → 🔑 OpenRouter API key**

**ไม่มีคีย์ก็ใช้งานได้:** กด **ข้ามไปก่อน** — ระบบ **ควบคุมเมาส์ด้วยมือ (ถ้ามีกล้อง)**, หน้า Help, การสั่ง "เปิด <โปรแกรม>" ด้วยการพิมพ์ ยังทำงานตามปกติ ส่วนการคุยกับ AI และสั่งด้วยเสียง (ถอดเสียง) ต้องมีคีย์ — ถ้ากดใช้โดยไม่มีคีย์ โปรแกรมจะบอกและเปิดหน้าต่างให้ใส่คีย์

ลำดับที่โปรแกรมหาคีย์: ① environment variable `OPENROUTER_API_KEY` → ② คีย์ที่บันทึกจากหน้าโปรแกรม → ③ ไฟล์ `k.py` (`API_KEY = "sk-or-..."`)

> ถ้าคีย์มาจาก environment variable หรือ `k.py` ปุ่มลบในเมนูจะลบไม่ได้ (ลบเฉพาะคีย์ที่บันทึกจากหน้าโปรแกรม) — และห้าม commit `k.py` ขึ้น GitHub

### ตัวเลือกบรรทัดคำสั่ง

| ตัวเลือก | ความหมาย |
|---|---|
| `--check` | ตรวจความพร้อมของระบบ และแสดงรายการจอภาพ |
| `--monitor N` | เปิดบนจอหมายเลข N (เริ่มที่ 1) |
| `--no-gesture` | ไม่เปิดระบบควบคุมเมาส์ด้วยมือ |
| `--no-tts` | ไม่อ่านออกเสียงตอบกลับ |
| `--threshold X` | กำหนดเกณฑ์เสียงพูดเอง (ปิดการวัดอัตโนมัติ) |

**ปุ่มลัด:** `ESC` ปิดหน้า Help (ถ้าเปิดอยู่) หรือออกจากโปรแกรม · `Enter` ส่งข้อความ
**พูดว่า** "ปิดระบบ" / "จบการทำงาน" / "goodbye jarvis" เพื่อปิดโปรแกรม

| **🧠 โมเดล AI** | พิมพ์ค้นหาหรือเลือกจากรายการ หรือกรอกรหัสโมเดลเอง · กด **🔄 โหลดรายการ** เพื่อดึงโมเดลทั้งหมดที่มีจริงจาก OpenRouter · มีผลเมื่อกด **บันทึก** และจำไว้ครั้งต่อไป |
| **เมาส์ด้วยมือ** | ความเร็วเคอร์เซอร์ 1.0–4.0× (ค่าเริ่มต้น 1.8) ยิ่งสูง ขยับนิ้วนิดเดียวเคอร์เซอร์ก็ไปไกล กรอบสีส้มในภาพกล้องจะเล็กลงตามให้ดู |
| **👆 การคลิก / ความนิ่ง** | จุดที่ใช้พาเคอร์เซอร์ (กลางฝ่ามือ/โคนนิ้วชี้/ปลายนิ้วชี้) · ความนิ่ง (พิกเซล) · ตรึงเคอร์เซอร์ตอนนิ้วเข้าใกล้กัน · ย้อนตำแหน่งก่อนจีบ · ระยะก่อนเริ่มลาก · ความแน่นของการจีบ — ปรับสดทันที มีปุ่มรีเซ็ตเป็นค่าแนะนำ (อธิบายด้านล่าง) |
| **🔑 API key** | ดูสถานะ/แหล่งที่มา · วางคีย์ใหม่ · 🗑 ลบคีย์ที่บันทึก (กดสองครั้งเพื่อยืนยัน) |
| **🎙 ไมโครโฟน** | เลือกอุปกรณ์ · มิเตอร์เสียงสด · เกณฑ์เสียงพูด (อัตโนมัติ/กำหนดเอง) · วัดเสียงห้อง · เวลาเงียบที่ถือว่าพูดจบ |

กด **บันทึก** เพื่อเก็บค่า (ขนาดตัวอักษร ความเร็วเมาส์ ไมค์) หรือ **ยกเลิก** เพื่อคืนค่าเดิม — ส่วน API key มีผลทันทีที่กดปุ่มของมันเอง เมนูเลื่อนขึ้น/ลงได้ด้วยลูกกลิ้งเมาส์เมื่อเนื้อหายาวเกินจอ

## 🚀 สั่ง AI เปิดโปรแกรม

พิมพ์หรือพูดได้เลย เช่น

> "เปิด paint" · "เปิดเว็บเบราว์เซอร์" · "ช่วยเปิดเครื่องคิดเลขหน่อยครับ" · "open notepad" · "เปิด youtube"

มี 2 ทางทำงาน:
1. **คำสั่งชัดเจน** (ขึ้นต้นด้วย เปิด/รัน/open/launch + ชื่อโปรแกรม) — เปิดทันทีโดยไม่ต้องรอ AI และใช้ได้แม้ไม่มี API key
2. **พูดอ้อมๆ** เช่น "ฉันอยากจดบันทึกหน่อย" — AI เป็นคนตัดสินใจ แล้วขอเปิดผ่านแท็กภายใน (ถูกตัดออกจากข้อความที่แสดงและอ่านออกเสียง)

**ความปลอดภัย:** เปิดได้เฉพาะโปรแกรมใน **รายการที่อนุญาต** เท่านั้น — ไม่มีการรันคำสั่งอิสระใดๆ แม้ AI จะขอมาก็ตาม

รายการเริ่มต้น: เว็บเบราว์เซอร์ (ค่าเริ่มต้นของเครื่อง) · Chrome · Edge · Firefox · Paint · Notepad · เครื่องคิดเลข · File Explorer · Word · Excel · PowerPoint · ตั้งค่า Windows · Task Manager · Snipping Tool · YouTube · Google · Gmail

### เพิ่มโปรแกรมของตัวเอง

สร้างไฟล์ `apps.json` ข้าง `tony_stark_interface.py` (ไม่มีการเปิด terminal/PowerShell ให้เป็นค่าเริ่มต้น — ถ้าต้องการ ให้เพิ่มเองที่นี่):

```json
{
  "obs": {
    "name": "OBS Studio",
    "aliases": ["obs", "โอบีเอส", "อัดหน้าจอ"],
    "target": "C:\\Program Files\\obs-studio\\bin\\64bit\\obs64.exe"
  },
  "docs": {
    "name": "โฟลเดอร์เอกสาร",
    "aliases": ["เอกสาร", "documents"],
    "target": "C:\\Users\\คุณ\\Documents"
  }
}
```

`target` เป็นได้ทั้งชื่อโปรแกรม พาธไฟล์/โฟลเดอร์ หรือ URL (`https://...`)

### 🎯 ทำให้คลิกแม่นและเคอร์เซอร์นิ่ง

ปัญหาเดิม: ตอนจีบนิ้วเพื่อคลิก ปลายนิ้วชี้ขยับ → เคอร์เซอร์เคลื่อนหนีเป้า วิธีแก้ที่ใช้ (ปรับได้ใน ⚙ ตั้งค่า → 👆):

1. **พาเคอร์เซอร์ด้วยกลางฝ่ามือ** (ค่าเริ่มต้น) — การงอ/จีบนิ้วแทบไม่ขยับฝ่ามือ เคอร์เซอร์จึงเคลื่อนเมื่อ *ทั้งมือ* ขยับเท่านั้น
2. **สายจูงกันมือสั่น (ความนิ่ง)** — มือขยับภายในวงรัศมีที่ตั้งไว้ เคอร์เซอร์ไม่ขยับเลย พอมือหลุดวงถึงเริ่มตามอย่างนุ่มนวล (ไม่กระโดด) ค่าคิดที่จอสูง 1080 พิกเซลและปรับตามจอ 4K ให้เอง
3. **ตรึงเคอร์เซอร์เมื่อกำลังจะจีบ** — พอนิ้วโป้งเริ่มเข้าใกล้นิ้วชี้ เคอร์เซอร์จะถูกล็อก (ขึ้นสถานะ `LOCK`) แล้วคลิกตรงนั้น
4. **ย้อนตำแหน่งก่อนจีบ** (ทางเลือก, ปิดเป็นค่าเริ่มต้น) — คลิกที่ตำแหน่งเมื่อ N มิลลิวินาทีก่อน มีประโยชน์เมื่อเลือกใช้ "ปลายนิ้วชี้" เป็นจุดอ้างอิง
5. **ลากเริ่มนุ่มนวล** — หลังจีบ ต้องขยับมือเกินระยะที่ตั้งไว้ถึงจะลาก และเคอร์เซอร์เริ่มลากจากศูนย์ (ไม่มีกระโดดตอนเริ่มลาก)

> ผลทดสอบจำลอง (ฝ่ามือนิ่ง ปลายนิ้วชี้สั่นระหว่างจีบ): ใช้ปลายนิ้วชี้แบบเดิมคลิกคลาดจากเป้า 44 พิกเซล → ใช้กลางฝ่ามือคลาด 0 พิกเซล และมือสั่น ±8 พิกเซลเคอร์เซอร์ไม่ขยับเมื่อเปิด "ความนิ่ง"

- ขณะเห็นสองมือในเฟรม เมาส์จะไม่ถูกควบคุม (กันคลิกพลาดตอนยกมือที่สองเข้ามา)
- กรอบสีส้มในภาพกล้อง = พื้นที่ที่มือต้องขยับเพื่อครอบคลุมทั้งจอ ปรับขนาดได้ด้วย *ความเร็วเมาส์* ในเมนูตั้งค่า
- ท่ามือจะควบคุมเคอร์เซอร์ **ภายในจอที่เลือก** (ดูหัวข้อถัดไป)

### ❓ หน้า Help

เปิดด้วยการโชว์มือ 10 นิ้ว หรือปุ่ม **❓ Help** — แสดงภาพท่ามือจาก [`gestures.svg`](gestures.svg) พร้อมคำอธิบาย
ปิดด้วย **👏 ปรบมือ 1 ครั้ง** · โชว์มือ 10 นิ้วอีกครั้ง · ESC · หรือปุ่ม ✕
(โปรแกรมฟังเสียงปรบมือเฉพาะตอนหน้า Help เปิดอยู่เท่านั้น)

## 🖥️ ใช้กับแว่น AR (XREAL One)

1. เสียบแว่น แล้วตั้งโหมดแสดงผลของ Windows เป็น **ขยายจอ (Extend)** เพื่อให้เห็นเป็นจอแยก
2. กดปุ่ม **🖥 จอภาพ** แล้วเลือกจอของแว่น (หรือเปิดด้วย `--monitor N`)
3. ท่ามือควบคุมเคอร์เซอร์ภายในจอที่เลือก และระบบจำจอไว้ใช้ครั้งหน้า (ถ้าจอนั้นไม่ได้เสียบอยู่ จะใช้จอหลักแทน)
4. หากต้องใช้โปรแกรมอื่นบนจอเดียวกัน กด **📌 Unpin** แล้วกดปุ่ม 📌 เล็กที่มุมจอเมื่อต้องการเรียก interface กลับ

## 🛠️ แก้ปัญหาเบื้องต้น

- **รัน `py -3.12` ไม่ได้** — ยังไม่ได้ติดตั้ง Python 3.12 (ดาวน์โหลดจาก python.org แล้วติ๊ก "py launcher")
- **ตรวจระบบ** — `python tony_stark_interface.py --check` บอกว่าขาดอะไรและเห็นจอที่ต่ออยู่
- **เปิดกล้องไม่ได้** — รัน `python test_cam.py` แล้วลองเปลี่ยน `JARVIS_CAMERA`
- **เคอร์เซอร์ต้องขยับมือไกลเกินไป / มือหลุดเฟรม** — เพิ่ม *ความเร็วเมาส์* ที่ ⚙ ตั้งค่า
- **จีบนิ้วแล้วเคอร์เซอร์เคลื่อนหนี / คลิกพลาด** — ที่ ⚙ ตั้งค่า → 👆 ใช้จุดอ้างอิง "กลางฝ่ามือ", เพิ่ม "ความนิ่ง" และเปิด "ตรึงเคอร์เซอร์เมื่อนิ้วเข้าใกล้กัน"
- **เคอร์เซอร์หน่วง/ต้องขยับมือเยอะกว่าจะเริ่มเคลื่อน** — ลด "ความนิ่ง" ลง (0 = ปิด)
- **คลิกไม่ติด / คลิกเอง** — ปรับ "ความแน่นของการจีบ" (ต่ำ = ต้องจีบชิดขึ้น)
- **เคอร์เซอร์ไวเกิน คุมยาก** — ลดความเร็วเมาส์ลง (1.0 = แบบเดิม)
- **ตัวอักษรเล็กเกินไป (เช่น จอ 4K)** — เพิ่มขนาดตัวอักษรที่ ⚙ ตั้งค่า (สูงสุด 400%) และเช็กว่าเปิด "ปรับตามความละเอียดจอ" อยู่
- **เปลี่ยนโมเดลแล้วตอบ error** — รหัสโมเดลอาจไม่ถูกต้องหรือบัญชีไม่มีสิทธิ์ใช้ ลองกด 🔄 โหลดรายการเพื่อเลือกจากโมเดลที่มีจริง
- **ไมค์ไม่จับเสียง / จับเสียงรบกวน** — ⚙ ตั้งค่า → เลือกอุปกรณ์ที่ถูกต้อง → "วัดเสียงห้อง"
- **ปรบมือปิด Help ไม่ติด / ติดเอง** — ปรับ `JARVIS_CLAP_MIN` และ `JARVIS_CLAP_RATIO`
- **ถอดเสียงไม่สำเร็จ / AI ไม่ตอบ** — ตรวจ API key ที่ ⚙ ตั้งค่า → 🔑 และ endpoint ของ OpenRouter
- **คลิกโปรแกรมอื่นไม่ได้** — กด **📌 Unpin**
- **ไม่เห็นจอของแว่นในรายการ** — ตั้งโหมดแสดงผลเป็น Extend แล้วเปิดเมนู 🖥 จอภาพใหม่
- **สั่งเปิดโปรแกรมแล้วบอกว่าเปิดไม่ได้** — โปรแกรมนั้นอาจยังไม่ได้ติดตั้ง หรือไม่ได้ลงทะเบียนชื่อกับ Windows — เพิ่มพาธเต็มใน `apps.json`
- **เสียงตอบกลับไม่ดัง** — ตรวจว่าติดตั้ง `edge-tts` แล้ว และไม่ได้เปิด `--no-tts`
